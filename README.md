## Projects

### 🗺️ QGIS RAN Audits

A comprehensive QGIS-based project for Radio Access Network (RAN) auditing, analysis, and optimization. This project provides tools and workflows for network engineers to perform systematic audits of 2G/3G/4G/5G networks.

**📁 Location**: [`qgis-ran-audits/`](qgis-ran-audits/)

**✨ Key Features**:
- 🗺️ Cell site visualization and GIS mapping
- 📊 Automated KPI audits (Availability, CSSR, DCR, HOSR)
- 🔗 Neighbour relation analysis and validation
- 📡 Coverage quality assessment (RSRP/RSRQ)
- ⚙️ Network optimization workflows
- 🐍 Python automation scripts
- 📝 Comprehensive documentation

**🚀 Quick Start**:
```bash
# Clone the repository
git clone https://github.com/heltonlimatrindade/helton-lima-trindade-senior-ran-engineer.git

# Navigate to project
cd helton-lima-trindade-senior-ran-engineer/qgis-ran-audits

# Run audit script
python3 scripts/ran_audits.py
```
